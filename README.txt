Creative Scheduler & Reminder
=============================

How to use
1. Unzip this folder.
2. Double-click index.html (opens in any modern browser). No install or server needed.

What is inside
- index.html : the whole app (HTML, CSS and JavaScript in one file).

Features
- Month calendar with colour-coded tasks.
- Type a task in a sentence ("Send invoice to Amina by Friday") and it lands on the right day,
  or on the lightest day of the next 30 days if you give no date.
- "Paste a full plan" box: paste projects, steps and dates (e.g. ASHTON: / 1. Project / - First concept - 15th Nov).
- People list with WhatsApp numbers (use the country code, e.g. 255712345678; a leading 0 is read as +255).
- "Remind" button opens a WhatsApp-style preview of the message; edit it, then Send on WhatsApp or Copy.

Notes
- Tasks and people are saved in your browser (localStorage) on the device you use.
- WhatsApp opens with the message ready; you press send yourself.
- The Google Font needs internet; offline it falls back to your system font.
